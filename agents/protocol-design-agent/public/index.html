Evidence-grounded design review

Review a protocol design against evidence.

Provide an existing study concept, synopsis or protocol excerpt. The agent identifies the stated design choices, checks them against public trial and literature evidence, and returns cited findings for expert review.

What the agent reviews

It evaluates what is present and marks missing or uncertain details as review gaps. It does not create or approve a protocol.
